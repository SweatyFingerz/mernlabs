# ShopKart - Full-Stack MERN Project

## Setup Instructions

### Prerequisites
- Node.js installed
- MongoDB URI / local instance

### Backend Setup
1. `cd backend` (or your backend folder)
2. `npm install`
3. Create a `.env` file based on `.env.example`
4. `npm run dev`

### Frontend Setup
1. `cd frontend`
2. `npm install`
3. `npm run dev`
